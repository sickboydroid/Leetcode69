## What is Sick169?

A curated problem tracker built around **169 hand-picked LeetCode contest problems from 2024+**. Not 75. Not 150. **169** — because we stopped at a suspiciously good number.

Problems are rated using [zerotrac's Elo-based system](https://github.com/zerotrac/leetcode_problem_rating), which gives a far more precise difficulty signal than LeetCode's own labels. A rating of 2000+ is genuinely hard. You'll know.

> *"The first 168 problems were easy. The last one will break you."*  
> — Everyone, eventually

---

## Why 169?

Because **168 felt incomplete** and **170 felt bloated**. Goldilocks engineering.  
Also `169 = 13²`. Unlucky number of problems for unlucky algorithms.

> *"They said do LeetCode every day. I said which 169?"*

---

## The List

- **129 Hard** · Rating ≥ 2000 · From Weekly + Biweekly Contests
- **40 Medium** · Rating 1400–2000 · Curated for technique diversity
- All problems from **January 2024 onwards** — fresh, not stale
- Spread across rating bands so you don't accidentally skip all the graph problems (you'll do them whether you like it or not)

## Features

| | Feature | Detail |
|-|---------|--------|
| ✅ | **Progress tracking** | Mark problems solved, watch that % climb |
| ⭐ | **Star system** | Bookmark problems to revisit (or avoid forever) |
| 🔢 | **Hidden ratings** | Reveal ratings individually or all at once |
| 🔍 | **Live search** | Find by title or problem ID |
| 🎚️ | **Filters** | Hide solved, show starred, filter by difficulty |
| ⌨️ | **Keyboard nav** | Full keyboard control — for the terminal purists |
| 💾 | **Export / Import** | Your progress, your JSON, your problem |
| 🔊 | **Sound effects** | Satisfying audio via Web Audio API |
| 📱 | **Responsive** | Works on mobile — for grinding on the bus |
| 🚫 | **No account** | All data lives in your browser. No cloud. No tracking. |

## Keyboard Shortcuts

> *Because clicking is for people who haven't memorized vim bindings yet.*

| Key | Action |
|-----|--------|
| `j` / `↓` | Move focus down |
| `k` / `↑` | Move focus up |
| `Enter` | Open problem in new tab |
| `Space` | Toggle solved |
| `s` | Toggle star |
| `r` | Toggle rating visibility |
| `/` | Focus search |
| `Esc` | Clear focus |

## Data & Privacy

- **Zero backend.** State lives in `localStorage`.
- **No tracking.** No analytics. No surveillance capitalism.

## Updating the Problem List

New contest dropped? Ratings updated? See [`PROBLEMS.md`](PROBLEMS.md) for a complete guide — written for both humans and LLMs — on how to:

- Fetch fresh rating data from [zerotrac/leetcode_problem_rating](https://github.com/zerotrac/leetcode_problem_rating)
- Re-run the selection script with custom thresholds
- Manually add or remove specific problems

## Tech Stack

> *No frameworks were harmed in the making of this app.*
